# Университеттің студенттерді тіркеу ақпараттық жүйесі

## Жобаның мақсаты
Университет студенттерін тіркеу және олардың мәліметтерін басқару процесін автоматтандыру.

## Негізгі мүмкіндіктер
- Студентті тіркеу
- Студент мәліметтерін қарау
- Студент мәліметтерін өзгерту
- Мамандыққа тіркеу
- Пәндерге тіркелу
- Студенттер тізімін қарау

## Жүйе пайдаланушылары
- Студент
- Тіркеуші
- Әкімші
