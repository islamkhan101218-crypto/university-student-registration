# Жүйеге қойылатын талаптар

## Функционалдық талаптар
1. Студенттерді жүйеге тіркеу.
2. Студенттің аты-жөнін, ЖСН-ын және байланыс ақпаратын сақтау.
3. Студентті факультет пен мамандыққа тіркеу.
4. Студент туралы мәліметтерді өңдеу.
5. Студенттер тізімін қарау.
6. Студенттерді пәндерге тіркеу.

## Функционалдық емес талаптар
1. Жүйе қолдануға ыңғайлы болуы керек.
2. Студенттердің жеке мәліметтері қорғалуы керек.
3. Жүйе ақпаратты жылдам өңдеуі керек.
## Студенттерді тіркеуге қосымша талаптар

1. Әр студентке бірегей Student ID берілуі керек.
2. Студенттің тіркелген күні сақталуы керек.
3. Жүйе студентті Student ID арқылы іздеуге мүмкіндік беруі керек.
