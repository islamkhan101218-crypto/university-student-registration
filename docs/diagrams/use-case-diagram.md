# Университеттің студенттерді тіркеу жүйесінің Use Case диаграммасы

## Акторлар
- Студент
- Тіркеуші
- Әкімші

## Жүйенің негізгі функциялары
1. Студентті тіркеу — Тіркеуші
2. Студент мәліметтерін өзгерту — Тіркеуші
3. Жеке мәліметтерді қарау — Студент
4. Пәндерге тіркелу — Студент
5. Пайдаланушыларды басқару — Әкімші

## Диаграмманың мақсаты
Пайдаланушылар мен ақпараттық жүйенің негізгі функциялары арасындағы байланысты сипаттау.
