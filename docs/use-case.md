# Университеттің студенттерді тіркеу ақпараттық жүйесі

## Акторлар

### Студент
- Жүйеге кіру
- Жеке мәліметтерін қарау
- Пәндерге тіркелу
- Тіркелген пәндерді қарау

### Тіркеуші
- Студентті тіркеу
- Студент мәліметтерін өзгерту
- Студенттер тізімін қарау

### Әкімші
- Пайдаланушыларды басқару
- Студенттердің мәліметтерін басқару
- Жүйенің жұмысын бақылау
